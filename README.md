# 🏖️ Departamento El Gallego

Sitio web desarrollado para la presentación y promoción de **Departamentos El Gallego**, un alojamiento turístico ubicado en **San Clemente del Tuyú, Buenos Aires**.

El proyecto tiene como objetivo ofrecer una experiencia visual atractiva e intuitiva, brindando a los visitantes toda la información necesaria sobre los departamentos, sus servicios, la ubicación y los medios de contacto.

---

## 📌 Descripción del proyecto

**Departamento El Gallego** es un sitio web responsive pensado para facilitar la búsqueda de información a turistas que desean hospedarse en San Clemente del Tuyú.

Desde la página los usuarios pueden:

- 🏠 Conocer los departamentos disponibles.
- 📸 Recorrer una galería de imágenes.
- 🎥 Visualizar videos de los alojamientos.
- ⭐ Consultar los servicios incluidos.
- 📍 Ver la ubicación mediante Google Maps.
- 📱 Contactarse fácilmente por WhatsApp.

## 🎨 Diseño

La identidad visual del sitio utiliza una paleta de colores cálidos inspirada en la playa y la tranquilidad de unas vacaciones.

**Colores principales**

- 🤎 Marrón
- 🤍 Blanco
- 🟤 Beige

La tipografía y los elementos visuales fueron seleccionados para transmitir una imagen cálida, sencilla y profesional.

---

## 📱 Responsive Design

El sitio fue desarrollado siguiendo un enfoque **responsive**, adaptándose correctamente a computadoras, tablets y teléfonos móviles para ofrecer una navegación cómoda desde cualquier dispositivo.
