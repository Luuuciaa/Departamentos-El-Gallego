# 🏖️ Departamento El Gallego

Sitio web desarrollado para la presentación y promoción de departamentos turísticos en la costa argentina.  
El objetivo del proyecto es brindar una experiencia visual atractiva, mostrando información sobre los alojamientos, servicios, ubicación y medios de contacto.

## 📌 Descripción del proyecto

**Departamento El Gallego** es una página web responsive diseñada para un alojamiento vacacional.

El sitio permite a los usuarios:

- 🏠 Conocer los departamentos disponibles.
- 📸 Visualizar imágenes de los alojamientos.
- ⭐ Consultar servicios incluidos.
- 📍 Ver la ubicación mediante mapa interactivo.
- 📱 Contactarse fácilmente mediante redes sociales y WhatsApp.

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap (componentes y diseño responsive)
- Google Fonts
- Font Awesome / Boxicons

## ✨ Características principales

✔ Diseño moderno orientado al turismo.  
✔ Interfaz simple e intuitiva.  
✔ Secciones organizadas para facilitar la navegación.

✔ Mapa de ubicación integrado.

## 🎨 Diseño

La identidad visual está basada en tonos cálidos y naturales para transmitir una sensación de comodidad y descanso:

- Beige
- Marrón
- Blanco
- Tonos relacionados con la playa

La tipografía y los elementos visuales fueron seleccionados para generar una estética cercana y profesional.
